Images des persos

Importe plusieurs images d'un coup : chaque fichier est associé à l'unité qui porte le même nom (ex. tiamat.webp, xuan-li.png, The Lumiwarden Diting.jpg). Les suffixes de skin (-1, -2) sont acceptés. Les images de sets (set_swiftrush.webp) et de modules (Wind_Transistor-Swiftrush.png) sont reconnues aussi.

Le plus rapide : copier / coller. Sur le site d'origine (ou n'importe où), clic droit sur l'image d'un perso → Copier l'image, puis reviens ici et fais Ctrl+V n'importe où dans la page. Le perso est reconnu tout seul grâce au nom de l'image. Tu peux aussi glisser-déposer des images (sur une carte = pour ce perso).

Pour une seule unité : clique sur sa vignette dans la liste, ou sur « Ajouter l'image » dans sa fiche build. Les images restent dans ce navigateur.

Où copier les images (clic droit sur l'image → Copier l'image, puis Ctrl+V ici) :
• Icônes des 27 sets : Prydwen – Matrix Effects
• Images des modules (et icônes de 21 sets) : Wiki – Module List
• Portraits des persos : er-tracker
Tout récupérer d'un coup (pack d'images)
  1. Clique sur Copier le script.
  2. Ouvre er-tracker (portraits) ou le wiki Module List (modules + icônes de sets).
  3. Appuie sur F12 → onglet Console, colle le script (Ctrl+V) et appuie sur Entrée. Si Chrome refuse le collage, tape d'abord allow pasting puis Entrée.
  4. Un fichier er-pack-….json se télécharge : importe-le ici avec ⋯ → Importer (JSON).
Si le bouton ne marche pas : clique dans le cadre ci-dessous (tout se sélectionne), puis Ctrl+C.
